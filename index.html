Bienvenidos a mi sitio

Soy Juan Manuel Montero

Soy un desarrollador Full-Stack en formación con experiencia práctica en la creación de aplicaciones organizadas y robustas, dominando JavaScript y TypeScript en entornos Node.js. Aplico buenas prácticas como la metodología BEM y la arquitectura MVC. Mis fortalezas radican en mi determinación, mi pensamiento analítico, mis habilidades de comunicación y relaciones interpersonales, listo para aportar valor y crecer en un equipo dinámico.

Mis servicios

Diseño y Maquetación de Interfaces (UI/UX Básico)

Me especializo en transformar diseños (mockups) en interfaces web funcionales usando HTML5 y CSS3. Mi enfoque está en crear experiencias de usuario claras y en la organización del código para facilitar el mantenimiento y la escalabilidad, implementando la metodología BEM para estructuras CSS coherentes.

Lógica y Desarrollo de Aplicaciones con JavaScript/TypeScript

Desarrollo la lógica necesaria para que las aplicaciones cobren vida, utilizando JavaScript y TypeScript para asegurar la robustez y la detección temprana de errores. Puedo implementar funcionalidades interactivas, manejar eventos y construir componentes reusables basados en principios de programación sólida.

Arquitectura de Código y Gestión de Datos (Patrones MVC)

Aplico la arquitectura de Patrones MVC para separar las responsabilidades del código y mantener las aplicaciones organizadas. Puedo desarrollar servicios básicos de back-end con Node.js y colaborar en la estructuración de la aplicación para una gestión eficiente de los datos y las rutas.
